개인정보 처리방침 – Toonfork

시행일: 2026년 11월 5일

Toonfork(이하 "앱")는 ol1n(이하 "당사")이 배포합니다. 이 방침은 앱이 여러분에 관한 정보를 어떻게 다루는지 설명합니다. 요약하면 당사는 개인정보를 수집하지 않습니다.

수집하지 않는 것

  • 앱에는 사용자 계정도 가입 절차도 없습니다.
  • 광고, 분석, 추적 도구, 광고나 측정을 위한 제3자 SDK가 없습니다.
  • 여러분, 기기, 읽는 내용에 관한 어떤 데이터도 당사로 보내지 않습니다.
  • 다른 앱이나 웹사이트에서 여러분을 추적하지 않습니다.

기기에 남는 것

앱은 기기에만 다음을 저장합니다.

  • 독자 프로필(어린이 / 성인)과 언어
  • 읽은 진행 상황, 게임북 상태(현재 노드, 찾은 결말), 편집기에서 만든 분기
  • 보유한 상품 목록(권한)과 스토어의 구매 영수증
  • 다운로드한 이야기 팩과 카탈로그 사본

이 데이터는 기기 밖으로 나가지 않으며, 앱을 삭제하면 함께 지워집니다. 직접 만든 게임북 분기는 여러분이 시스템 공유 시트로 직접 선택한 수신자에게 보낼 때만 기기를 벗어납니다.

구매

앱 내 구매는 Apple(App Store) 또는 Google(Google Play)이 각자의 약관과 개인정보 처리방침에 따라 처리합니다. 당사는 이름, 결제 카드, 이메일 주소를 볼 수 없습니다. 앱은 스토어로부터 상품을 보유하고 있다는 확인만 받아 기기에 저장합니다.

콘텐츠 다운로드

앱은 카탈로그, 표지, 이야기 팩을 GitHub Pages와 GitHub Releases(GitHub, Inc.)에서 내려받습니다. 다른 웹 호스트와 마찬가지로 GitHub는 다운로드 시 기기의 IP 주소와 기술적인 요청 데이터를 받아 자체 방침에 따라 처리합니다: https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement. 당사는 이 데이터를 받지 않으며 여러분과 연결하지도 않습니다.

어린이

앱에는 어린이 프로필이 있습니다. 구매와 성인 프로필 전환은 보호자 확인으로 보호됩니다. 어린이를 포함해 누구의 개인정보도 수집하지 않습니다.

이용자의 권리

당사는 여러분에 관한 개인정보를 처리하지 않으므로 열람·정정·삭제할 것이 없습니다. 기기에 저장된 데이터는 전적으로 여러분이 관리합니다. 문의는 business@olin.now로 보내 주세요. 거주 지역의 개인정보 보호 기관에 민원을 제기할 수도 있습니다.

변경

이 방침이 바뀌면 새 시행일과 함께 이 페이지에 새 버전을 게시합니다.
