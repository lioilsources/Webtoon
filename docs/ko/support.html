문제는 GitHub 이슈 트래커에서도 신고할 수 있습니다.

자주 묻는 질문

다른 기기에서 팩을 구매했거나 앱을 다시 설치했습니다. 어떻게 되찾나요?

설정을 열고 "구매 복원"을 누르세요. 구매할 때 사용한 Apple ID 또는 Google 계정을 쓰세요. App Store에서는 가족 공유 구성원도 팩을 받습니다.

팩이나 게임북이 다운로드되지 않습니다.

다운로드에는 인터넷 연결과 충분한 저장 공간이 필요합니다(팩 하나는 약 50~150MB). Wi-Fi에서 다시 시도해 보세요. 중단된 다운로드는 이어서 받습니다. 설치가 끝나면 모든 것이 오프라인에서 작동합니다.

읽는 언어는 어떻게 바꾸나요?

설정 → 말풍선 언어. 모든 이야기와 게임북을 12개 언어로 읽을 수 있습니다: 체코어, 영어, 독일어, 이탈리아어, 프랑스어, 폴란드어, 포르투갈어(브라질), 일본어, 한국어, 베트남어, 러시아어, 우크라이나어. 앱 자체는 45개 언어를 지원합니다.

어린이 프로필이란?

어린이 프로필은 로맨스 이야기, 팩, 성인용 드라마를 숨깁니다. 구매와 성인 프로필 전환은 보호자 확인으로 보호됩니다.

게임북은 어떻게 작동하나요?

챕터가 끝나면 다음 전개를 고릅니다. 진행 상황과 찾은 결말은 기기에 저장되며, 언제든 한 단계 뒤로 가거나 처음부터 다시 시작할 수 있습니다.

어려운 주제를 다루는 이야기가 있습니다.

성인용 드라마에는 섭식 장애와 죽음에 대한 생각이 나옵니다. 해당되는 부분이 있다면 도움을 요청하세요. 한국에서는 자살예방상담전화 109, 유럽에서는 116 123 또는 가까운 위기 상담 전화로 연락할 수 있습니다.
