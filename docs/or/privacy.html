ଗୋପନୀୟତା ନୀତି – Toonfork

କାର୍ଯ୍ୟକାରୀ ତାରିଖ: 5 ନଭେମ୍ବର 2026

Toonfork ("ଆପ୍") ol1n ("ଆମେ") ପ୍ରକାଶ କରିଛି। ଆପ୍ ଆପଣଙ୍କ ବିଷୟରେ ତଥ୍ୟ କିପରି ସମ୍ଭାଳେ ଏହି ନୀତି ତାହା ବୁଝାଏ। ସଂକ୍ଷେପରେ: ଆମେ କୌଣସି ବ୍ୟକ୍ତିଗତ ତଥ୍ୟ ସଂଗ୍ରହ କରୁନାହୁଁ।

ଆମେ ଯାହା ସଂଗ୍ରହ କରୁନାହୁଁ

  • ଆପ୍‌ରେ କୌଣସି ଉପଯୋଗକର୍ତ୍ତା ଖାତା ବା ସାଇନ୍-ଅପ୍ ନାହିଁ।
  • ଏଥିରେ ବିଜ୍ଞାପନ, ବିଶ୍ଳେଷଣ, ଟ୍ରାକିଂ ଉପକରଣ କିମ୍ବା ବିଜ୍ଞାପନ ବା ମାପ ପାଇଁ ତୃତୀୟ ପକ୍ଷର SDK ନାହିଁ।
  • ଏହା ଆପଣଙ୍କ, ଆପଣଙ୍କ ଡିଭାଇସ୍ କିମ୍ବା ଆପଣ କଣ ପଢ଼ନ୍ତି ସେ ବିଷୟରେ କୌଣସି ତଥ୍ୟ ଆମକୁ ପଠାଏ ନାହିଁ।
  • ଏହା ଅନ୍ୟ ଆପ୍ କିମ୍ବା ୱେବସାଇଟ୍‌ରେ ଆପଣଙ୍କୁ ଅନୁସରଣ କରେ ନାହିଁ।

ଆପଣଙ୍କ ଡିଭାଇସ୍‌ରେ ଯାହା ରହେ

ଆପ୍ କେବଳ ଆପଣଙ୍କ ଡିଭାଇସ୍‌ରେ ସଞ୍ଚୟ କରେ:

  • ଆପଣଙ୍କ ପାଠକ ପ୍ରୋଫାଇଲ୍ (ପିଲା / ବୟସ୍କ) ଓ ଭାଷା;
  • ଆପଣଙ୍କ ପଢ଼ାର ଅଗ୍ରଗତି, ଗେମବୁକ୍ ଅବସ୍ଥା (ବର୍ତ୍ତମାନର ନୋଡ୍, ମିଳିଥିବା ସମାପ୍ତି) ଏବଂ ସମ୍ପାଦକରେ ବନାଇଥିବା ଶାଖା;
  • ଆପଣ ଯେଉଁ ଉତ୍ପାଦର ମାଲିକ ସେଗୁଡ଼ିକର ତାଲିକା (ଅଧିକାର) ଓ ଷ୍ଟୋରର କିଣା ରସିଦ;
  • ଡାଉନଲୋଡ୍ ହୋଇଥିବା କାହାଣୀ-ପ୍ୟାକ୍ ଓ କ୍ୟାଟାଲଗ୍‌ର ଏକ ନକଲ।

ଏହି ତଥ୍ୟ କେବେ ଆପଣଙ୍କ ଡିଭାଇସ୍ ଛାଡ଼େ ନାହିଁ, ଆପ୍ ଅନଇନଷ୍ଟଲ୍ କଲେ ତାହା ମୁଛିଯାଏ। ଆପଣ ବନାଇଥିବା ଗେମବୁକ୍ ଶାଖା ଡିଭାଇସ୍ ଛାଡ଼େ କେବଳ ଯେତେବେଳେ ଆପଣ ନିଜେ ସିଷ୍ଟମ୍ ସେୟାର୍ ଶିଟ୍ ଦ୍ୱାରା ଆପଣଙ୍କ ବାଛିଥିବା ପ୍ରାପକଙ୍କୁ ପଠାନ୍ତି।

କିଣାକିଣି

ଆପ୍ ଭିତରର କିଣାକିଣି Apple (App Store) ବା Google (Google Play) ସେମାନଙ୍କ ନିଜ ନିୟମ ଓ ଗୋପନୀୟତା ନୀତି ଅନୁସାରେ ପ୍ରକ୍ରିୟା କରେ। ଆମେ କେବେ ଆପଣଙ୍କ ନାମ, ଦେୟ କାର୍ଡ ବା ଇମେଲ୍ ଠିକଣା ଦେଖୁନାହୁଁ। ଆପଣ ଏକ ଉତ୍ପାଦର ମାଲିକ ବୋଲି ଷ୍ଟୋରରୁ କେବଳ ନିଶ୍ଚିତକରଣ ଆପ୍ ପାଏ, ଏବଂ ତାହା ଆପଣଙ୍କ ଡିଭାଇସ୍‌ରେ ସଞ୍ଚୟ କରେ।

ବିଷୟବସ୍ତୁ ଡାଉନଲୋଡ୍

ଆପ୍ କ୍ୟାଟାଲଗ୍, ମଲାଟ ଓ କାହାଣୀ-ପ୍ୟାକ୍ GitHub Pages ଓ GitHub Releases (GitHub, Inc.) ରୁ ଡାଉନଲୋଡ୍ କରେ। ଯେକୌଣସି ୱେବ୍ ହୋଷ୍ଟ୍ ପରି, ଡାଉନଲୋଡ୍ ବେଳେ GitHub ଆପଣଙ୍କ ଡିଭାଇସ୍‌ର IP ଠିକଣା ଓ ବୈଷୟିକ ଅନୁରୋଧ ତଥ୍ୟ ପାଏ ଏବଂ ନିଜ ନୀତି ଅନୁସାରେ ସମ୍ଭାଳେ: https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement। ଆମେ ଏହି ତଥ୍ୟ ପାଉନାହୁଁ ଓ ଆପଣଙ୍କ ସହ ଯୋଡ଼ୁନାହୁଁ।

ପିଲା

ଆପ୍‌ରେ ଏକ ପିଲା ପ୍ରୋଫାଇଲ୍ ଅଛି। କିଣାକିଣି ଓ ବୟସ୍କ ପ୍ରୋଫାଇଲ୍‌କୁ ବଦଳ ଅଭିଭାବକ ଗେଟ୍ ଦ୍ୱାରା ସୁରକ୍ଷିତ। ଆମେ ପିଲା କିମ୍ବା ଅନ୍ୟ କାହାଠାରୁ ବ୍ୟକ୍ତିଗତ ତଥ୍ୟ ସଂଗ୍ରହ କରୁନାହୁଁ।

ଆପଣଙ୍କ ଅଧିକାର

ଆମେ ଆପଣଙ୍କ ବିଷୟରେ କୌଣସି ବ୍ୟକ୍ତିଗତ ତଥ୍ୟ ପ୍ରକ୍ରିୟା କରୁନଥିବାରୁ ଦେଖାଇବା, ସଂଶୋଧନ ବା ବିଲୋପ କରିବା ପାଇଁ ଆମ ପାଖରେ କିଛି ନାହିଁ। ଆପଣଙ୍କ ଡିଭାଇସ୍‌ରେ ସଞ୍ଚିତ ତଥ୍ୟ ଉପରେ ଆପଣଙ୍କର ପୂର୍ଣ୍ଣ ନିୟନ୍ତ୍ରଣ ଅଛି। ପ୍ରଶ୍ନ ପାଇଁ business@olin.now କୁ ଯୋଗାଯୋଗ କରନ୍ତୁ। ଆପଣ ଆପଣଙ୍କ ତଥ୍ୟ ସୁରକ୍ଷା ପ୍ରାଧିକରଣକୁ ମଧ୍ୟ ଅଭିଯୋଗ କରିପାରିବେ।

ପରିବର୍ତ୍ତନ

ଏହି ନୀତି ବଦଳିଲେ ଆମେ ନୂଆ କାର୍ଯ୍ୟକାରୀ ତାରିଖ ସହ ଏହି ପୃଷ୍ଠାରେ ନୂଆ ସଂସ୍କରଣ ପ୍ରକାଶ କରିବୁ।
