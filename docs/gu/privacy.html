ગોપનીયતા નીતિ – Toonfork

અસરકારક તારીખ: 5 નવેમ્બર 2026

Toonfork ("ઍપ") ol1n ("અમે") દ્વારા પ્રકાશિત છે. આ નીતિ સમજાવે છે કે ઍપ તમારા વિશેની માહિતી કેવી રીતે સંભાળે છે. ટૂંકમાં: અમે કોઈ વ્યક્તિગત માહિતી એકઠી કરતા નથી.

અમે જે એકઠું કરતા નથી

  • ઍપમાં યુઝર ખાતાં નથી અને સાઇન-અપ નથી.
  • તેમાં જાહેરાતો, વિશ્લેષણ, ટ્રૅકિંગ સાધનો કે જાહેરાત અથવા માપન માટેના ત્રીજા પક્ષના SDK નથી.
  • તે અમને તમારા, તમારા ઉપકરણ કે તમે શું વાંચો છો તે વિશે કોઈ માહિતી મોકલતી નથી.
  • તે અન્ય ઍપ કે વેબસાઇટ પર તમને અનુસરતી નથી.

તમારા ઉપકરણ પર શું રહે છે

ઍપ ફક્ત તમારા ઉપકરણ પર સાચવે છે:

  • તમારી વાચક પ્રોફાઇલ (બાળકો / પુખ્ત) અને ભાષા;
  • તમારી વાંચનની પ્રગતિ, ગેમબુકની સ્થિતિ (વર્તમાન નોડ, મળેલા અંત) અને એડિટરમાં બનાવેલી કોઈપણ શાખાઓ;
  • તમે ધરાવો છો તે ઉત્પાદનોની યાદી (હક) અને સ્ટોરની ખરીદી રસીદો;
  • ડાઉનલોડ કરેલા વાર્તા-પૅક અને કૅટલૉગની નકલ.

આ માહિતી ક્યારેય તમારું ઉપકરણ છોડતી નથી, અને ઍપ કાઢી નાખવાથી તે ભૂંસાઈ જાય છે. તમે બનાવેલી ગેમબુક શાખા ત્યારે જ ઉપકરણ છોડે છે જ્યારે તમે જાતે સિસ્ટમની શેર શીટ દ્વારા તમે પસંદ કરેલા પ્રાપ્તકર્તાને મોકલો.

ખરીદી

ઍપ-અંદરની ખરીદી Apple (App Store) અથવા Google (Google Play) તેમની પોતાની શરતો અને ગોપનીયતા નીતિઓ હેઠળ પ્રક્રિયા કરે છે. અમે ક્યારેય તમારું નામ, ચુકવણી કાર્ડ કે ઇમેઇલ સરનામું જોતા નથી. ઍપ સ્ટોર પાસેથી ફક્ત પુષ્ટિ મેળવે છે કે તમે ઉત્પાદન ધરાવો છો, અને તે તમારા ઉપકરણ પર સાચવે છે.

સામગ્રી ડાઉનલોડ

ઍપ કૅટલૉગ, કવર અને વાર્તા-પૅક GitHub Pages અને GitHub Releases (GitHub, Inc.) પરથી ડાઉનલોડ કરે છે. કોઈપણ વેબ હોસ્ટની જેમ, ડાઉનલોડ વખતે GitHub તમારા ઉપકરણનું IP સરનામું અને તકનીકી વિનંતી ડેટા મેળવે છે અને પોતાની નીતિ હેઠળ સંભાળે છે: https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement. અમે આ ડેટા મેળવતા નથી અને તમારી સાથે જોડતા નથી.

બાળકો

ઍપ બાળકોની પ્રોફાઇલ આપે છે. ખરીદી અને પુખ્ત પ્રોફાઇલમાં ફેરફાર માતાપિતા માટેના ગેટથી સુરક્ષિત છે. અમે બાળકો કે અન્ય કોઈ પાસેથી વ્યક્તિગત માહિતી એકઠી કરતા નથી.

તમારા અધિકારો

અમે તમારા વિશે કોઈ વ્યક્તિગત માહિતી પર પ્રક્રિયા કરતા નથી, તેથી જોવા, સુધારવા કે કાઢી નાખવા જેવું અમારી પાસે કશું નથી. તમારા ઉપકરણ પર સંગ્રહિત માહિતી પર તમારું પૂર્ણ નિયંત્રણ છે. પ્રશ્નો માટે business@olin.now પર સંપર્ક કરો. તમે તમારા ડેટા સુરક્ષા અધિકારી પાસે ફરિયાદ પણ કરી શકો છો.

ફેરફારો

જો આ નીતિ બદલાય, તો અમે નવી અસરકારક તારીખ સાથે આ પાના પર નવી આવૃત્તિ પ્રકાશિત કરીશું.
