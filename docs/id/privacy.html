Kebijakan Privasi – Toonfork

Berlaku sejak: 5 November 2026

Toonfork ("aplikasi") diterbitkan oleh ol1n ("kami"). Kebijakan ini menjelaskan bagaimana aplikasi menangani informasi tentang kamu. Singkatnya: kami tidak mengumpulkan data pribadi.

Yang tidak kami kumpulkan

  • Aplikasi tidak memiliki akun pengguna dan tidak ada pendaftaran.
  • Aplikasi tidak berisi iklan, analitik, alat pelacakan, maupun SDK pihak ketiga untuk iklan atau pengukuran.
  • Aplikasi tidak mengirimkan data tentang kamu, perangkatmu, atau apa yang kamu baca kepada kami.
  • Aplikasi tidak melacakmu di aplikasi atau situs web lain.

Yang tetap ada di perangkatmu

Aplikasi hanya menyimpan di perangkatmu:

  • profil pembacamu (Anak / Dewasa) dan bahasa;
  • kemajuan membaca, status buku permainan (simpul saat ini, akhir yang ditemukan), dan cabang yang kamu buat di editor;
  • daftar produk yang kamu miliki (hak akses) dan tanda terima pembelian dari toko;
  • paket cerita yang diunduh dan salinan katalog.

Data ini tidak pernah meninggalkan perangkatmu, dan menghapus aplikasi akan menghapusnya. Cabang buku permainan yang kamu buat hanya meninggalkan perangkat jika kamu sendiri mengirimnya lewat lembar berbagi sistem ke penerima pilihanmu.

Pembelian

Pembelian dalam aplikasi diproses oleh Apple (App Store) atau Google (Google Play) berdasarkan ketentuan dan kebijakan privasi mereka sendiri. Kami tidak pernah melihat namamu, kartu pembayaran, atau alamat email. Aplikasi hanya menerima konfirmasi dari toko bahwa kamu memiliki suatu produk, dan menyimpannya di perangkatmu.

Pengunduhan konten

Aplikasi mengunduh katalog, sampul, dan paket cerita dari GitHub Pages dan GitHub Releases (GitHub, Inc.). Seperti web host lain, GitHub menerima alamat IP perangkatmu dan data teknis permintaan saat konten diunduh, dan menanganinya sesuai kebijakannya sendiri: https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement. Kami tidak menerima data ini dan tidak mengaitkannya denganmu.

Anak-anak

Aplikasi menyediakan profil Anak. Pembelian dan peralihan ke profil Dewasa dilindungi gerbang orang tua. Kami tidak mengumpulkan data pribadi dari anak-anak maupun siapa pun.

Hak-hakmu

Karena kami tidak memproses data pribadi tentang kamu, tidak ada yang bisa kami berikan aksesnya, perbaiki, atau hapus. Kamu sepenuhnya mengendalikan data yang tersimpan di perangkatmu. Untuk pertanyaan, hubungi business@olin.now. Kamu juga dapat mengajukan keluhan ke otoritas perlindungan data.

Perubahan

Jika kebijakan ini berubah, kami akan menerbitkan versi baru di halaman ini dengan tanggal berlaku baru.

Kontak
