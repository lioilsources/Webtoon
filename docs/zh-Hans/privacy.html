隐私政策 – Toonfork

生效日期：2026 年 11 月 5 日

Toonfork（“应用”）由 ol1n（“我们”）发布。本政策说明应用如何处理与您有关的信息。简而言之：我们不收集任何个人数据。

我们不收集的内容

  • 应用没有用户账号，也无需注册。
  • 应用不含广告、分析、跟踪工具，也不含用于广告或衡量的第三方 SDK。
  • 应用不会向我们发送任何关于您、您的设备或您阅读内容的数据。
  • 应用不会在其他应用或网站上跟踪您。

留在您设备上的内容

应用仅在您的设备上存储：

  • 您的读者资料（儿童 / 成人）和语言；
  • 您的阅读进度、游戏书状态（当前节点、已发现的结局）以及您在编辑器中创建的分支；
  • 您拥有的商品列表（权益）和商店的购买凭证；
  • 已下载的故事包和目录副本。

这些数据永远不会离开您的设备，卸载应用即会删除。您创建的游戏书分支只有在您自己通过系统分享面板发送给您选择的接收者时，才会离开设备。

购买

应用内购买由 Apple（App Store）或 Google（Google Play）按其自身的条款和隐私政策处理。我们从不会看到您的姓名、支付卡或电子邮件地址。应用仅从商店收到您拥有某商品的确认，并将其存储在您的设备上。

内容下载

应用从 GitHub Pages 和 GitHub Releases（GitHub, Inc.）下载目录、封面和故事包。与任何网络主机一样，GitHub 会在下载时接收您设备的 IP 地址和技术请求数据，并按其自身政策处理：https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement。我们不会收到这些数据，也不会将其与您关联。

儿童

应用提供儿童资料。购买以及切换到成人资料均受家长验证保护。我们不会从儿童或任何人处收集个人数据。

您的权利

由于我们不处理任何与您有关的个人数据，因此没有可供访问、更正或删除的内容。存储在您设备上的数据完全由您掌控。如有疑问，请联系 business@olin.now。您也可以向所在地的数据保护机构投诉。

变更

如本政策发生变更，我们将在本页面发布新版本，并注明新的生效日期。

联系方式

ol1n, business@olin.now
