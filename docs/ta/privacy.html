தனியுரிமைக் கொள்கை – Toonfork

நடைமுறைக்கு வரும் தேதி: 5 நவம்பர் 2026

Toonfork ("செயலி") ஐ ol1n ("நாங்கள்") வெளியிடுகிறார். உங்களைப் பற்றிய தகவல்களை செயலி எவ்வாறு கையாளுகிறது என்பதை இக்கொள்கை விளக்குகிறது. சுருக்கமாக: நாங்கள் எந்த தனிப்பட்ட தரவையும் சேகரிப்பதில்லை.

நாங்கள் சேகரிக்காதவை

  • செயலியில் பயனர் கணக்குகளோ பதிவுசெய்தலோ இல்லை.
  • அதில் விளம்பரங்கள், பகுப்பாய்வு, கண்காணிப்புக் கருவிகள் அல்லது விளம்பரம்/அளவீட்டுக்கான மூன்றாம் தரப்பு SDK-கள் இல்லை.
  • உங்களைப் பற்றியோ உங்கள் சாதனத்தைப் பற்றியோ நீங்கள் படிப்பதைப் பற்றியோ எந்தத் தரவையும் அது எங்களுக்கு அனுப்புவதில்லை.
  • பிற செயலிகளிலும் இணையதளங்களிலும் அது உங்களைப் பின்தொடர்வதில்லை.

உங்கள் சாதனத்தில் எஞ்சுபவை

செயலி உங்கள் சாதனத்தில் மட்டும் சேமிப்பது:

  • உங்கள் வாசகர் சுயவிவரம் (குழந்தைகள் / பெரியவர்கள்) மற்றும் மொழி;
  • உங்கள் வாசிப்பு முன்னேற்றம், கேம்புக் நிலை (தற்போதைய முனை, கண்டறிந்த முடிவுகள்) மற்றும் தொகுப்பியில் நீங்கள் உருவாக்கும் கிளைகள்;
  • நீங்கள் வைத்திருக்கும் பொருட்களின் பட்டியல் (உரிமைகள்) மற்றும் கடையின் கொள்முதல் ரசீதுகள்;
  • பதிவிறக்கிய கதைத் தொகுப்புகள் மற்றும் பட்டியலின் நகல்.

இந்தத் தரவு உங்கள் சாதனத்தை விட்டு ஒருபோதும் வெளியேறாது, செயலியை நீக்கினால் அழிந்துவிடும். நீங்கள் உருவாக்கிய கேம்புக் கிளை, நீங்களே கணினிப் பகிர்வுத் தாள் வழியாக நீங்கள் தேர்ந்தெடுத்த பெறுநருக்கு அனுப்பினால் மட்டுமே சாதனத்தை விட்டு வெளியேறும்.

கொள்முதல்கள்

செயலிக்குள் கொள்முதல்களை Apple (App Store) அல்லது Google (Google Play) தங்கள் சொந்த விதிமுறைகள் மற்றும் தனியுரிமைக் கொள்கைகளின்படி செயலாக்குகின்றன. உங்கள் பெயர், கட்டண அட்டை அல்லது மின்னஞ்சல் முகவரியை நாங்கள் ஒருபோதும் பார்ப்பதில்லை. நீங்கள் ஒரு பொருளை வைத்திருக்கிறீர்கள் என்ற உறுதிப்படுத்தலை மட்டுமே செயலி கடையிலிருந்து பெற்று உங்கள் சாதனத்தில் சேமிக்கிறது.

உள்ளடக்கப் பதிவிறக்கங்கள்

செயலி பட்டியல், அட்டைகள் மற்றும் கதைத் தொகுப்புகளை GitHub Pages மற்றும் GitHub Releases (GitHub, Inc.) இலிருந்து பதிவிறக்குகிறது. எந்த இணைய ஹோஸ்டையும் போல, பதிவிறக்கத்தின்போது GitHub உங்கள் சாதனத்தின் IP முகவரியையும் தொழில்நுட்பக் கோரிக்கைத் தரவையும் பெற்று தனது கொள்கையின்படி கையாளுகிறது: https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement. இந்தத் தரவை நாங்கள் பெறுவதில்லை, உங்களுடன் இணைப்பதுமில்லை.

குழந்தைகள்

செயலியில் குழந்தைகள் சுயவிவரம் உள்ளது. கொள்முதல்களும் பெரியவர் சுயவிவரத்துக்கு மாறுவதும் பெற்றோர் வாயிலால் பாதுகாக்கப்படுகின்றன. குழந்தைகளிடமிருந்தோ வேறு எவரிடமிருந்தோ நாங்கள் தனிப்பட்ட தரவை சேகரிப்பதில்லை.

உங்கள் உரிமைகள்

உங்களைப் பற்றிய தனிப்பட்ட தரவை நாங்கள் செயலாக்காததால், அணுக, திருத்த அல்லது நீக்க எங்களிடம் எதுவும் இல்லை. உங்கள் சாதனத்தில் சேமித்த தரவு முழுவதும் உங்கள் கட்டுப்பாட்டில் உள்ளது. கேள்விகளுக்கு business@olin.now ஐத் தொடர்புகொள்ளுங்கள். உங்கள் தரவுப் பாதுகாப்பு அதிகாரசபையிடமும் புகார் அளிக்கலாம்.
