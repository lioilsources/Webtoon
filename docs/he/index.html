TOONFORK

גללו ובחרו את דרככם

Toonfork הוא קורא שקט שעובד בלי חיבור לקומיקס בגלילה אנכית. חמישה עשר סיפורים בחינם מההפעלה הראשונה, פאנלים נבחרים מתעוררים לחיים בלולאות קצרות ומונפשות, וספרי משחק בחינם נותנים לכם להחליט מה קורה הלאה.

  • סיפורים וספרי משחק ב-12 שפות, האפליקציה עצמה ב-45
  • חבילות סיפורים אופציונליות: ילדים, רומנטיקה, גיבורי על
  • פרופיל ילדים עם שער הורים
  • בלי חשבון, בלי פרסומות, בלי מעקב
