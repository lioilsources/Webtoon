رازداری کی پالیسی – Toonfork

نفاذ کی تاریخ: 5 نومبر 2026

Toonfork ("ایپ") کو ol1n ("ہم") شائع کرتا ہے۔ یہ پالیسی بتاتی ہے کہ ایپ آپ کے بارے میں معلومات کو کیسے سنبھالتی ہے۔ مختصراً: ہم کوئی ذاتی ڈیٹا جمع نہیں کرتے۔

جو ہم جمع نہیں کرتے

  • ایپ میں صارف اکاؤنٹس یا سائن اپ نہیں ہے۔
  • اس میں اشتہارات، تجزیات، ٹریکنگ ٹولز یا اشتہار/پیمائش کے لیے تیسرے فریق کے SDK نہیں ہیں۔
  • یہ ہمیں آپ کے، آپ کے آلے یا آپ کے پڑھنے کے بارے میں کوئی ڈیٹا نہیں بھیجتی۔
  • یہ دیگر ایپس یا ویب سائٹس پر آپ کا پیچھا نہیں کرتی۔

آپ کے آلے پر کیا رہتا ہے

ایپ صرف آپ کے آلے پر محفوظ کرتی ہے:

  • آپ کا قاری پروفائل (بچے / بالغ) اور زبان؛
  • آپ کی پڑھنے کی پیش رفت، گیم بک کی حالت (موجودہ نوڈ، دریافت شدہ اختتام) اور ایڈیٹر میں آپ کی بنائی ہوئی شاخیں؛
  • آپ کی ملکیت کی مصنوعات کی فہرست (حقوق) اور اسٹور کی خریداری کی رسیدیں؛
  • ڈاؤن لوڈ کیے گئے کہانی پیک اور کیٹلاگ کی ایک کاپی۔

یہ ڈیٹا کبھی آپ کا آلہ نہیں چھوڑتا، اور ایپ ان انسٹال کرنے سے مٹ جاتا ہے۔ آپ کی بنائی ہوئی گیم بک شاخ آلے سے صرف تب نکلتی ہے جب آپ خود سسٹم شیئر شیٹ کے ذریعے اپنے منتخب وصول کنندہ کو بھیجیں۔

خریداریاں

ایپ کے اندر کی خریداریاں Apple (App Store) یا Google (Google Play) اپنی شرائط اور رازداری کی پالیسیوں کے مطابق پروسیس کرتے ہیں۔ ہم آپ کا نام، ادائیگی کارڈ یا ای میل پتہ کبھی نہیں دیکھتے۔ ایپ کو اسٹور سے صرف یہ تصدیق ملتی ہے کہ آپ کے پاس کوئی مصنوعہ ہے، اور وہ اسے آپ کے آلے پر محفوظ کرتی ہے۔

مواد کی ڈاؤن لوڈز

ایپ کیٹلاگ، سرورق اور کہانی پیک GitHub Pages اور GitHub Releases (GitHub, Inc.) سے ڈاؤن لوڈ کرتی ہے۔ کسی بھی ویب ہوسٹ کی طرح، ڈاؤن لوڈ کے وقت GitHub کو آپ کے آلے کا IP پتہ اور تکنیکی درخواست ڈیٹا ملتا ہے اور وہ اپنی پالیسی کے مطابق اسے سنبھالتا ہے: https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement۔ ہمیں یہ ڈیٹا نہیں ملتا اور ہم اسے آپ سے نہیں جوڑتے۔

بچے

ایپ میں بچوں کا پروفائل ہے۔ خریداریاں اور بالغ پروفائل پر منتقلی والدین کے گیٹ سے محفوظ ہیں۔ ہم بچوں یا کسی اور سے ذاتی ڈیٹا جمع نہیں کرتے۔

آپ کے حقوق

چونکہ ہم آپ کے بارے میں کوئی ذاتی ڈیٹا پروسیس نہیں کرتے، اس لیے ہمارے پاس رسائی، درستی یا حذف کرنے کے لیے کچھ نہیں ہے۔ آپ کے آلے پر محفوظ ڈیٹا پر آپ کا مکمل اختیار ہے۔ سوالات کے لیے business@olin.now سے رابطہ کریں۔ آپ اپنی ڈیٹا تحفظ اتھارٹی کے پاس شکایت بھی کر سکتے ہیں۔
