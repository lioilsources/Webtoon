隱私權政策 – Toonfork

生效日期：2026 年 11 月 5 日

Toonfork（「應用程式」）由 ol1n（「我們」）發佈。本政策說明應用程式如何處理與您相關的資訊。簡而言之：我們不蒐集任何個人資料。

我們不蒐集的內容

  • 應用程式沒有使用者帳號，也無需註冊。
  • 應用程式不含廣告、分析、追蹤工具，也不含用於廣告或衡量的第三方 SDK。
  • 應用程式不會向我們傳送任何關於您、您的裝置或您閱讀內容的資料。
  • 應用程式不會在其他應用程式或網站上追蹤您。

留在您裝置上的內容

應用程式僅在您的裝置上儲存：

  • 您的讀者檔案（兒童 / 成人）與語言；
  • 您的閱讀進度、遊戲書狀態（目前節點、已發現的結局）以及您在編輯器中建立的分支；
  • 您擁有的商品清單（權益）與商店的購買收據；
  • 已下載的故事包與目錄副本。

這些資料永遠不會離開您的裝置，解除安裝應用程式即會刪除。您建立的遊戲書分支只有在您自行透過系統分享面板傳送給您選擇的接收者時，才會離開裝置。

購買

應用程式內購買由 Apple（App Store）或 Google（Google Play）依其自身條款與隱私權政策處理。我們從不會看到您的姓名、付款卡或電子郵件地址。應用程式僅從商店收到您擁有某商品的確認，並將其儲存在您的裝置上。

內容下載

應用程式從 GitHub Pages 與 GitHub Releases（GitHub, Inc.）下載目錄、封面與故事包。與任何網路主機一樣，GitHub 會在下載時接收您裝置的 IP 位址與技術請求資料，並依其自身政策處理：https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement。我們不會收到這些資料，也不會將其與您關聯。

兒童

應用程式提供兒童檔案。購買以及切換至成人檔案均受家長驗證保護。我們不會從兒童或任何人蒐集個人資料。

您的權利

由於我們不處理任何與您相關的個人資料，因此沒有可供存取、更正或刪除的內容。儲存在您裝置上的資料完全由您掌控。如有疑問，請聯絡 business@olin.now。您也可以向所在地的資料保護主管機關申訴。

變更

若本政策有所變更，我們將在本頁面發佈新版本，並註明新的生效日期。

聯絡方式

ol1n, business@olin.now
