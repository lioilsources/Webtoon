ความช่วยเหลือ

Toonfork — คอมิกแนวตั้งและเกมบุ๊ก

ติดต่อ

พบข้อบกพร่อง คำแปลผิด หรือมีคำถามหรือไม่ ยินดีช่วยเหลือ

อีเมล: business@olin.now

โดยปกติเราตอบกลับภายในไม่กี่วันทำการ ยินดีรับภาษาเช็กและภาษาอังกฤษ

คุณยังรายงานปัญหาได้ที่ ตัวติดตามปัญหาของ GitHub

คำถามที่พบบ่อย

ฉันซื้อชุดบนอุปกรณ์อื่นหรือติดตั้งแอปใหม่ จะกู้คืนได้อย่างไร

เปิดการตั้งค่าแล้วแตะ “กู้คืนการซื้อ” ใช้ Apple ID หรือบัญชี Google เดียวกับที่ใช้ซื้อ ใน App Store สมาชิก “แชร์กับครอบครัว” ก็ได้รับชุดเรื่องราวด้วย

ชุดเรื่องราวหรือเกมบุ๊กดาวน์โหลดไม่ได้

การดาวน์โหลดต้องใช้การเชื่อมต่ออินเทอร์เน็ตและพื้นที่ว่างเพียงพอ (หนึ่งชุดประมาณ 50–150 MB) ลองใหม่ผ่าน Wi-Fi การดาวน์โหลดที่ขาดตอนจะต่อเนื่องได้ เมื่อติดตั้งแล้ว ทุกอย่างทำงานออฟไลน์

จะเปลี่ยนภาษาที่อ่านได้อย่างไร

การตั้งค่า → ภาษาของบอลลูนคำพูด ทุกเรื่องและเกมบุ๊กอ่านได้ใน 12 ภาษา: เช็ก อังกฤษ เยอรมัน อิตาลี ฝรั่งเศส โปแลนด์ โปรตุเกส (บราซิล) ญี่ปุ่น เกาหลี เวียดนาม รัสเซีย และยูเครน ตัวแอปเองรองรับ 45 ภาษา

โปรไฟล์เด็กคืออะไร

โปรไฟล์เด็กซ่อนเรื่องโรแมนซ์ ชุดเรื่องราว และดราม่าสำหรับผู้ใหญ่ การซื้อและการสลับไปยังโปรไฟล์ผู้ใหญ่อยู่หลังประตูผู้ปกครอง

เกมบุ๊กทำงานอย่างไร

เมื่อจบบท คุณเลือกว่าจะเกิดอะไรต่อไป ความคืบหน้าและตอนจบที่พบจะถูกเก็บไว้บนอุปกรณ์ คุณย้อนกลับหนึ่งขั้นหรือเริ่มใหม่ได้ทุกเมื่อ

บางเรื่องพูดถึงหัวข้อที่ละเอียดอ่อน

ดราม่าสำหรับผู้ใหญ่มีเรื่องความผิดปกติทางการกินและความคิดเกี่ยวกับความตาย หากเรื่องใดกระทบใจคุณ โปรดขอความช่วยเหลือ: ในยุโรปโทร 116 123 หรือสายด่วนวิกฤตในพื้นที่ของคุณ
