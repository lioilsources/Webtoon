സ്വകാര്യതാ നയം – Toonfork

പ്രാബല്യ തീയതി: 2026 നവംബർ 5

Toonfork ("ആപ്പ്") പ്രസിദ്ധീകരിക്കുന്നത് ol1n ("ഞങ്ങൾ") ആണ്. ആപ്പ് നിങ്ങളെക്കുറിച്ചുള്ള വിവരങ്ങൾ എങ്ങനെ കൈകാര്യം ചെയ്യുന്നുവെന്ന് ഈ നയം വിശദീകരിക്കുന്നു. ചുരുക്കത്തിൽ: ഞങ്ങൾ വ്യക്തിഗത വിവരങ്ങളൊന്നും ശേഖരിക്കുന്നില്ല.

ഞങ്ങൾ ശേഖരിക്കാത്തത്

  • ആപ്പിന് ഉപയോക്തൃ അക്കൗണ്ടുകളോ സൈൻ-അപ്പോ ഇല്ല.
  • അതിൽ പരസ്യമോ അനലിറ്റിക്സോ ട്രാക്കിംഗ് ഉപകരണങ്ങളോ പരസ്യത്തിനോ അളവിനോ ഉള്ള മൂന്നാം കക്ഷി SDK-കളോ ഇല്ല.
  • നിങ്ങളെയോ നിങ്ങളുടെ ഉപകരണത്തെയോ നിങ്ങൾ വായിക്കുന്നതിനെയോ കുറിച്ചുള്ള ഒരു വിവരവും അത് ഞങ്ങൾക്ക് അയയ്ക്കുന്നില്ല.
  • മറ്റ് ആപ്പുകളിലോ വെബ്സൈറ്റുകളിലോ അത് നിങ്ങളെ പിന്തുടരുന്നില്ല.

നിങ്ങളുടെ ഉപകരണത്തിൽ അവശേഷിക്കുന്നത്

ആപ്പ് നിങ്ങളുടെ ഉപകരണത്തിൽ മാത്രം സൂക്ഷിക്കുന്നു:

  • നിങ്ങളുടെ വായനക്കാരുടെ പ്രൊഫൈൽ (കുട്ടികൾ / മുതിർന്നവർ), ഭാഷ;
  • നിങ്ങളുടെ വായനാ പുരോഗതി, ഗെയിംബുക്ക് നില (നിലവിലെ നോഡ്, കണ്ടെത്തിയ അവസാനങ്ങൾ), എഡിറ്ററിൽ നിങ്ങളുണ്ടാക്കുന്ന ശാഖകൾ;
  • നിങ്ങൾ സ്വന്തമാക്കിയ ഉൽപ്പന്നങ്ങളുടെ പട്ടികയും (അവകാശങ്ങൾ) സ്റ്റോറിൽ നിന്നുള്ള വാങ്ങൽ രസീതുകളും;
  • ഡൗൺലോഡ് ചെയ്ത കഥാ പായ്ക്കുകളും കാറ്റലോഗിന്റെ ഒരു പകർപ്പും.

ഈ വിവരങ്ങൾ ഒരിക്കലും നിങ്ങളുടെ ഉപകരണം വിട്ടുപോകുന്നില്ല, ആപ്പ് അൺഇൻസ്റ്റാൾ ചെയ്താൽ അവ മായ്ക്കപ്പെടും. നിങ്ങളുണ്ടാക്കിയ ഗെയിംബുക്ക് ശാഖ ഉപകരണം വിടുന്നത് നിങ്ങൾ തന്നെ സിസ്റ്റം ഷെയർ ഷീറ്റ് വഴി നിങ്ങൾ തിരഞ്ഞെടുത്ത സ്വീകർത്താവിന് അയച്ചാൽ മാത്രമാണ്.

വാങ്ങലുകൾ

ആപ്പിനുള്ളിലെ വാങ്ങലുകൾ Apple (App Store) അല്ലെങ്കിൽ Google (Google Play) അവരുടെ സ്വന്തം നിബന്ധനകളും സ്വകാര്യതാ നയങ്ങളും അനുസരിച്ച് പ്രോസസ്സ് ചെയ്യുന്നു. നിങ്ങളുടെ പേരോ പേയ്മെന്റ് കാർഡോ ഇമെയിൽ വിലാസമോ ഞങ്ങൾ ഒരിക്കലും കാണുന്നില്ല. നിങ്ങൾ ഒരു ഉൽപ്പന്നം സ്വന്തമാക്കിയെന്ന സ്ഥിരീകരണം മാത്രമാണ് ആപ്പിന് സ്റ്റോറിൽ നിന്ന് ലഭിക്കുന്നത്, അത് നിങ്ങളുടെ ഉപകരണത്തിൽ സൂക്ഷിക്കുന്നു.

ഉള്ളടക്ക ഡൗൺലോഡുകൾ

ആപ്പ് കാറ്റലോഗ്, കവറുകൾ, കഥാ പായ്ക്കുകൾ എന്നിവ GitHub Pages, GitHub Releases (GitHub, Inc.) എന്നിവയിൽ നിന്ന് ഡൗൺലോഡ് ചെയ്യുന്നു. ഏതൊരു വെബ് ഹോസ്റ്റിനെയും പോലെ, ഉള്ളടക്കം ഡൗൺലോഡ് ചെയ്യുമ്പോൾ GitHub നിങ്ങളുടെ ഉപകരണത്തിന്റെ IP വിലാസവും സാങ്കേതിക അഭ്യർത്ഥനാ വിവരങ്ങളും സ്വീകരിക്കുകയും സ്വന്തം നയപ്രകാരം കൈകാര്യം ചെയ്യുകയും ചെയ്യുന്നു: https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement. ഞങ്ങൾക്ക് ഈ വിവരങ്ങൾ ലഭിക്കുന്നില്ല, നിങ്ങളുമായി ബന്ധിപ്പിക്കുന്നുമില്ല.

കുട്ടികൾ

ആപ്പിൽ കുട്ടികളുടെ പ്രൊഫൈൽ ഉണ്ട്. വാങ്ങലുകളും മുതിർന്നവരുടെ പ്രൊഫൈലിലേക്കുള്ള മാറ്റവും രക്ഷിതാക്കൾക്കുള്ള ഗേറ്റ് കൊണ്ട് സംരക്ഷിതമാണ്. കുട്ടികളിൽ നിന്നോ മറ്റാരിൽ നിന്നോ ഞങ്ങൾ വ്യക്തിഗത വിവരങ്ങൾ ശേഖരിക്കുന്നില്ല.

നിങ്ങളുടെ അവകാശങ്ങൾ

നിങ്ങളെക്കുറിച്ചുള്ള വ്യക്തിഗത വിവരങ്ങളൊന്നും ഞങ്ങൾ പ്രോസസ്സ് ചെയ്യാത്തതിനാൽ, ലഭ്യമാക്കാനോ തിരുത്താനോ ഇല്ലാതാക്കാനോ ഞങ്ങളുടെ പക്കൽ ഒന്നുമില്ല. നിങ്ങളുടെ ഉപകരണത്തിൽ സൂക്ഷിച്ച വിവരങ്ങൾ പൂർണമായും നിങ്ങളുടെ നിയന്ത്രണത്തിലാണ്. ചോദ്യങ്ങൾക്ക് business@olin.now ൽ ബന്ധപ്പെടുക. നിങ്ങൾക്ക് ഡാറ്റാ സംരക്ഷണ അതോറിറ്റിക്കും പരാതി നൽകാം.

മാറ്റങ്ങൾ

ഈ നയം മാറിയാൽ, പുതിയ പ്രാബല്യ തീയതിയോടെ പുതിയ പതിപ്പ് ഈ പേജിൽ പ്രസിദ്ധീകരിക്കും.
